第 D2 步（网页：论文同款交互式建网界面）。现有网页在 src/ctrlnet/webmap/（Leaflet，离线）。新增一个“论文模式”页面（例如 /thesis，或替换默认首页并保留旧仪表盘为 /dashboard），尽量复刻规格第 1、2 节描述的界面与交互：
0. 先根据 docs/target/target.txt 全文与现有代码，补充完善 docs/target/target_spec.md（功能、算法公式、差距分析，保留其中的截图文字描述与离线约束），再开始下面的实现。
1. 布局：白底；左侧约 60% 宽地图（左上缩放控件、左下比例尺），右侧约 40% 纵向滚动面板，依次为浅绿色标题条的“点库”“线库”“角库”“网库”，简单表格+输入框+灰色按钮（“构线”“构角”“精度计算”），每行“删除”按钮；地图下方说明区（蓝色小标题“#1 角度测量原理”“#2 坐标转换原理”“#3 精度估算原理”，内容取自论文第 3 章要点）。中文字体用系统已有字体。
2. 底图：离线底图，覆盖论文示例区域徐州（约 117.1–117.3°E、34.15–34.25°N）：用 scripts/fetch_dem.py 的方式一次性下载 Copernicus GLO-30 N34 E117 瓦片，裁剪该区域，渲染成浅色晕渲+分层设色+等高线 PNG（配色浅淡，接近论文浅色地图风格），作为 Leaflet imageOverlay 或本地 XYZ 瓦片；小样本提交到 data/sample/（≤3MB），原始瓦片放 data/cache/。不得使用任何在线瓦片。
3. 交互：地图点击选点→红色水滴形标记（本地 SVG/divIcon），点号自动递增，点库显示序号/经度/纬度（6 位小数）；点可设为已知/未知（点库中切换）；“构线”输入起点、终点→线库显示编号/起点/终点/距离 m（4 位小数）/方位 °（4 位小数），地图画绿色虚线；“构角”输入起点(后视)/测站/终点(前视)→角库显示角值，地图测站处画小圆弧；删除点级联删除相关线和角；网库：等级下拉（二等…二级）+按平均边长自动建议，勾选观测边/观测角（未勾选=仅图形边），“精度计算”按钮调用后端 API（复用 D1 的 thesis 计算）返回：最弱点、Qxx/Qyy、M、是否满足限差、边长相对中误差分母表、误差椭圆（地图上绘制，可开关、可调放大倍数）。观测边显示红色实线，新增（优化）观测黄色实线，未观测边绿色虚线。“导出坐标转换结果”“导出角度拓扑”按钮显示论文格式文本。工程可保存/读取（复用 SQLite store），可一键“载入论文算例 1/算例 2”。
4. 后端 API 与测试 tests/test_thesis_web.py（TestClient）：建点/线/角、计算、导出接口。
5. 用 Playwright 无头 Chromium 做一次端到端测试：载入算例 1，点击精度计算，确认结果表出现。
