第 B3 步（下一阶段：本地离线网页地图 + 影像配准）。先阅读 docs/redesign_plan.md §7 接口、§8 界面，以及原方案 docs/original_plan.md 第 3、4 节。上一步已生成 data/sample/dem_sample.* 与 data/sample/terrain_project.json。
1. src/ctrlnet/webmap/：用 FastAPI（或 Flask）+ uvicorn 做一个只绑定 127.0.0.1 的本地服务（默认端口 8765，命令 `ctrlnet-web` 或 `python -m ctrlnet.webmap`）。前端用静态 Leaflet 页面，Leaflet 的 JS/CSS 下载后放进包内 static/（离线可用，不依赖 CDN）。底图：后端把 DEM 晕渲（可叠加分层设色）渲染为 PNG 作为 imageOverlay（或简单 XYZ 瓦片）；图层：控制点（固定/待定不同符号）、观测线（通视绿、遮挡红，点击显示净空/距离）、误差椭圆（多边形）、等高线（GeoJSON）。API：GET /api/project、GET /api/layers、GET /api/overlay/hillshade.png、GET /api/profile?from=&to= 返回剖面 JSON；页面点击两点可画剖面（简单 SVG 或 canvas 图）。不暴露公网，不加鉴权以外的复杂功能。
2. src/ctrlnet/registration.py：6 参数仿射配准：输入 ≥3 对控制点（像素 col,row ↔ E,N），最小二乘求参数，返回残差、RMS、每点残差，<3 点或共线抛错；支持把 PNG/GeoTIFF 图像配准后输出 world file（.pgw/.tfw）。测试 tests/test_registration.py（已知仿射精确恢复、加噪 RMS 合理、共线报错）。在网页上提供一个“导入影像”演示：data/sample/ 中生成一张示例扫描图（例如用等高线图渲染出的 PNG 加一个已知仿射变换），用 4 个控制点配准并以半透明叠加，残差 RMS 显示在页面上。
3. tests/test_webmap.py：用 FastAPI TestClient（或 Flask test client）测试各 API 返回 200 和关键字段。
4. 截图：启动服务（后台，127.0.0.1），用 Playwright 无头 Chromium 截图保存 outputs/webmap_screenshot.png（以及 outputs/webmap_profile_screenshot.png 显示一个剖面）。Playwright 已装在 /workspace/venvs/lab（/workspace/venvs/lab/bin/python -m playwright ...），若不可用就在 .venv 里 pip install playwright 并 playwright install chromium。截图后关闭服务。
