# 目标效果规格（target_spec）

来源：docs/target/target.pdf（43 页本科论文《基于在线地图的网页端控制网设计与精度估算系统》，百度地图 JS API），全文 docs/target/target.txt，图片 docs/target/figs/img-<页>-<序>.png。
**本项目约束：完全离线**——只能用本机离线底图（DEM 晕渲/分层设色、本地矢量底图），**不得加载任何在线瓦片或在线地图 API（包括 OSM、百度、天地图）**；服务只绑定 127.0.0.1。论文中的“百度在线地图”在本项目中一律替换为“离线底图”。

## 1. 系统功能（论文第 2–4 章）
1. 地图显示：缩放/平移控件、比例尺；在地图上点击选点放置红色标记（点标记 Marker），点号自动递增。
2. 点库：右侧表格（序号、经度、纬度、操作[删除]）；选点后自动入库，删除点会同步删除关联的线和角（图 4-9 点库更新、图 4-10 删除点）。
3. 线库：输入框“起点”“终点”+按钮“构线”；表格（编号、起点、终点、距离 m（4 位小数）、方位 °（4 位小数）、操作[删除]）；地图上画**绿色虚线**（图 4-11 构线、图 4-12 删除线）。距离与方位由两点经纬度计算（论文第 3 章：经纬度→高斯投影平面坐标，球面/椭球距离与方位角，图 3-2 测方位角、图 3-4 测边）。
4. 角库：输入“起点(后视)”“测站”“终点(前视)”+按钮“构角”；表格（编号、起点、测站、终点、角度、操作）；地图上在测站处画**小圆弧角标记**（图 4-13 构角、图 5-4）。
5. 网库：控制网等级下拉框（二等/三等/四等/一级/二级，参数见表 3-1）、“精度计算”按钮；可勾选哪些边作为观测边、哪些角为观测角（边角网）。
6. 精度估算：间接平差 Qxx=(BᵀPB)⁻¹；最弱点 M=Mw·sqrt(Qxx+Qyy)（Mw=单位权中误差，测角网取 Mw=测角中误差，例 Mw=10″）；与限差（如 2 cm）比较给出“满足精度要求”；各边“边长相对中误差分母”表（图 5-7、5-12），最弱边与等级限差比较；误差椭圆 E、F、φE（公式 3-38/3-39）在地图上绘制。
7. 优化：在原网基础上增加观测角/观测边（新加观测用不同颜色显示：图 5-13 中已观测边为红色实线，新增观测为黄色实线，未观测边绿色虚线），重新计算比较最弱点中误差。
8. 导出：点号+经纬度导出、坐标转换结果以文本形式显示（图 5-5：“点1；x，y”逐行），角度拓扑导出为文本（图 5-6：`[-1,1,2;-2,-1,2;...]`，未知点用编号，已知点 8、9 分别记为 -1、-2）。
9. 页面下部有说明区（“#1 角度测量原理”“#2 坐标转换原理”等标题+说明/链接，图 4-6 测量原理说明）。

### 表 3-1 控制网参数（等级：平均边长 km / 测角中误差 ″ / a mm / b ppm / 最弱边相对中误差）
二等 9 / 1 / ≤10 / ≤2 / 1/12万；三等 5 / 1.8 / ≤10 / ≤5 / 1/8万；四等 2 / 2.5 / ≤10 / ≤10 / 1/4.5万；一级 1 / 5.0 / ≤10 / ≤10 / 1/2万；二级 <1 / 10 / ≤15 / ≤20 / 1/1万。
论文测距先验：σS = a + b·S（线性相加，S 单位 km），定权 P=σ0²/σS²；测角网各角权为 1。

## 2. 界面布局（据截图）
- 整页白底、简洁：左侧约 60% 宽为地图（左上角缩放平移控件，左下比例尺）；右侧约 40% 为纵向滚动的一列面板，依次为浅绿色标题条的“点库”“线库”“角库”“网库”，每个是简单表格+输入框+灰色按钮（“构线”“构角”“精度计算”），每行带“删除”按钮。

## 4. 与当前 ctrlnet-design 的差距
已有：平面/水准/GNSS 平差引擎、误差椭圆、相对精度、可靠性、优化器、DEM 通视、SQLite 工程、报告、Leaflet 离线网页（深色仪表盘风格，展示 DEM 演示网、方案切换、剖面、配准）。
缺失（要做成目标效果）：
1. **交互式建网**：地图点击选点→点库；输入起/终点“构线”→线库；输入三点“构角”→角库；表格行删除并级联；当前网页基本只读。
2. **论文同款界面**：白底、左地图右四库面板（浅绿标题条、表格、灰按钮）、下方说明区；红色点标记、绿色虚线、角圆弧标记、已观测红实线/新增黄实线。
3. **网库与等级**：表 3-1 等级下拉，自动按平均边长建议等级；观测边/观测角勾选；“精度计算”按钮→最弱点 M、是否满足限差、边长相对中误差分母表、误差椭圆显示开关。
4. **论文约定的计算选项**：σS=a+b·S 线性模型（可选，与现有平方和模型并存）、测角网 P=I 与 Mw、Q 的 mm²/″² 单位约定、经纬度→高斯 3° 带投影（CGCS2000/WGS84）、球面/椭球距离与方位、坐标转换文本导出与角度拓扑导出（-1/-2 记法）。
5. **离线底图**：徐州示例区域的离线底图（Copernicus GLO-30 N34 E117 瓦片离线制作的浅色晕渲+分层设色+等高线底图，配色尽量浅淡接近论文截图的浅色风格；不使用 OSM 或任何在线/第三方地图数据，运行时绝不访问网络）。
6. **算例复现**：算例 1 由坐标+拓扑重算 Qxx/Qyy/M；算例 2 只能近似。
7. **截图对照**：Playwright 生成与图 4-1…4-5、4-11、4-13、5-1、5-2、5-4、5-9、5-11、5-13 对应的截图及左右对比图。
