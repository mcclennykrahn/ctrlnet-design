# 目标效果规格（target_spec）

来源：`docs/target/target.pdf`（43 页本科论文《基于在线地图的网页端控制网设计与精度估算系统》，原系统基于百度地图 JavaScript API GL/v3.0），全文转录 `docs/target/target.txt`，图片 `docs/target/figs/img-<页>-<序>.png`。
本文把论文第 1–6 章（重点第 3–5 章）整理为可实现的规格，并记录当前 `ctrlnet-design` 已实现/尚缺的内容。**本文保留论文截图的文字描述，供看不到图片时复刻界面。**

> **硬约束：完全离线。** 本项目不得加载任何在线瓦片、在线地图 API 或第三方地图数据（包括 OSM、百度、高德、天地图、Google、任何 CDN 地图资源），也不使用 OSM 数据。运行时只能使用本机由 Copernicus DEM 生成的离线底图；网页服务只绑定 `127.0.0.1`。论文中的“百度在线地图”在本项目中一律替换为“离线 DEM 底图”。

## 1. 论文第 1–2 章背景与系统目标

1. 传统控制网设计靠纸质地图人工量算距离、角度，再列误差方程估算精度，效率低、返工多。
2. 论文希望把“地图选点 → 构线/构角 → 生成拓扑 → 精度估算 → 优化设计 → 导出成果”放在一个网页端完成。
3. 论文对比了 Google、高德、百度地图 API；最终采用百度地图 JavaScript API 的 `Map`、`Marker`、`Polyline`、`Label`、`NavigationControl`、`ScaleControl`、`getDistance` 等接口。本项目不移植这些在线接口，只移植其**交互与计算语义**。
4. 论文明确只做**平面控制网**，不考虑高程与通视；地图点击只提供经纬度，精度估算在高斯平面上进行。
5. 原系统功能链：地图选点（右键点击）→ 点库自动编号/经纬度 → 输入起终点构线（距离、方位角）→ 输入起边/终边构角（角度）→ 选择等级 → 导出经纬度/角度拓扑 → 外部矩阵程序平差 → 根据最弱点/最弱边判断是否满足限差 → 增加观测值优化。

### 1.1 原系统页面组成（据第 4 章正文）

- 页面包含：百度在线地图、点库、构线文本框与“构线”按钮、线库、构角输入框与“构角”按钮、角库、控制网等级下拉菜单。
- 左右分栏：Bootstrap `col-md-8` 放地图（`#map` 高 600 px），`col-md-4` 放数据区；本项目的目标布局按截图取约 60% / 40%。
- 右侧数据区从上到下依次为：点库、线库（含构线操作框）、角库（含构角操作框）、网库/等级下拉。
- 点库、线库、角库均有浅色底纹标题条，按钮约 80×34 px，文本框与按钮同高；字体为系统字体。
- 表格由 JavaScript 动态生成；每行最后一列为“删除”。

### 1.2 原系统交互细节（第 3.1、4.4 节）

1. 左键拖拽平移、滚轮缩放；左上角有缩放/平移控件，左下角有比例尺。
2. 地图**右键**点击生成点；弹出 `confirm("当前位置：lng, lat, 确定保存当前坐标么？")`，确认后加点。
3. 点号按点击顺序递增，点标记上显示点号，点库同步显示“点号、经度、纬度”。
4. 删除点：
   - 若删除的是当前最大点号，下一个新点从该点号继续；
   - 若删除的不是最大点号，则比它大的所有点号自动减一，线库/角库引用的点号同步更新。
   - 删除点会级联删除所有关联的线和角。
5. 构线：输入起点、终点编号，点击“构线”；线库增加“编号、起点、终点、距离、方位”，地图画绿色虚线。删除线只删线，不删点。
6. 构角：输入起点（后视）、测站、终点（前视），点击“构角”；角库增加“编号、起点、测站、终点、角度”，地图在测站处画小圆弧。
7. 等级下拉：二等、三等、四等、一级、二级；不同等级取表 3-1 参数参与精度估算。
8. 原系统把结果导出为文本，再粘贴到外部矩阵程序；论文展望也承认“计算结果不能直接画回地图（误差椭圆）”。本项目要求把误差椭圆直接画回地图。

## 2. 目标界面布局（据图 4-1～4-6、5-1～5-13 的截图文字描述）

### 2.1 整页

- 白底、简洁，无深色主题；中文字体使用系统已有字体（如 Noto Sans CJK / 文泉驿 / Microsoft YaHei / PingFang SC 的回退栈）。
- 左侧约 **60%** 宽为地图区；地图高度约占视口 60–65%，其下方为说明区。
- 右侧约 **40%** 宽为纵向滚动的一列面板，不再分左右子列。
- 面板顺序固定：**点库 → 线库 → 角库 → 网库**。
- 每个面板有浅绿色标题条（论文 Bootstrap 的 `bg-success` 风格），白底、细边框。
- 表格为简单表格：表头浅灰、行间细线、数字右对齐；操作列“删除”为小号灰/红色文字按钮。
- 输入框为普通边框，按钮为灰色（非主色大按钮）：构线、构角、精度计算、保存/读取、导出。

### 2.2 点库

- 标题条文字：**点库**。
- 表头：**点号 | 经度 | 纬度 | 类型 | 操作**。
- 经度、纬度各保留 **6 位小数**；本项目的点还保存高斯平面 `x`（北）、`y`（东）用于计算。
- “类型”列可切换“未知/已知”，已知点用不同颜色或加粗标识。
- 行尾“删除”按钮；删除点级联删除关联线、角。
- 目标页面在地图点击选点时自动加点；同时提供“清空”或“新建工程”入口。

### 2.3 线库

- 标题条文字：**线库**。
- 操作行：`起点 [输入] 终点 [输入] [构线]`。
- 表头：**编号 | 起点 | 终点 | 距离 m | 方位 ° | 操作**。
- 距离保留 **4 位小数**，方位角保留 **4 位小数**（0–360°，从北顺时针）。
- 默认线型：**绿色虚线**；观测边在网库勾选后变为**红色实线**；优化新增观测边为**黄色实线**。
- 行尾“删除”只删该线，不删端点。

### 2.4 角库

- 标题条文字：**角库**。
- 操作行：`起点(后视) [输入] 测站 [输入] 终点(前视) [输入] [构角]`。
- 表头：**编号 | 起点(后视) | 测站 | 终点(前视) | 角度 ° | 操作**。
- 角度为测站处从后视方向顺时针到前视方向的水平角，取值 0–360°，显示 4 位小数。
- 地图在测站处画**小圆弧 + 两条短方向线**；未观测角淡灰，观测角橙色/蓝色，优化新增角黄色。

### 2.5 网库

- 标题条文字：**网库**。
- 等级下拉：**二等 / 三等 / 四等 / 一级 / 二级**。
- 根据全部线库边的平均边长自动给出**建议等级**，并显示平均边长；允许用户手动改选（手动后不再自动覆盖，提供“采用建议”）。
- 观测选择：
  - “观测边”复选列表（列出线库编号与端点）；
  - “观测角”复选列表（列出角库编号与三点）；
  - 未勾选的边/角只作为**图形边/图形角**参与网形显示，不进入 B 矩阵。
  - 另设“优化新增观测”区，可把当前未观测的边/角加入优化方案；新增观测以黄色显示。
- 按钮：**精度计算**（灰色）。
- 计算结果区：
  - 最弱点编号、`Qxx`、`Qyy`、`M`（论文数值口径）、是否满足限差（默认 2 cm）；
  - “边长相对中误差分母”表：线号、端点、边长、分母、与等级限差比较；
  - 误差椭圆：地图上按点位绘制，提供“显示/隐藏”开关与“放大倍数”输入；
  - 若有优化新增观测，显示优化前后最弱点中误差对比。
- “导出坐标转换结果”“导出角度拓扑”按钮：在页面中以论文格式文本显示（可复制），不访问网络。
- 工程区：工程名输入、保存、已存工程下拉、读取；“载入论文算例 1 / 算例 2”一键按钮。
- 地图下方说明区（蓝色小标题）：
  - **#1 角度测量原理**：球面三角形、余弦定理/正弦定理、方位角象限修正、角度=两方位角之差；
  - **#2 坐标转换原理**：WGS84/CGCS2000 经纬度 → 3° 带高斯投影，中央子午线 117°E、500 km 假东；
  - **#3 精度估算原理**：间接平差 `V=BX-L`、`Q=(BᵀPB)⁻¹`、`M=Mw√(Qxx+Qyy)`、误差椭圆 E/F/φE 与限差。

## 3. 算法与公式（第 3 章，重点）

### 3.1 高斯-克吕格投影正算（式 3-1～3-9）

- 椭球：CGCS2000（`a=6378137`，`1/f=298.257222101`）或 WGS84；本项目默认 CGCS2000。
- 3° 带中央子午线：`L0 = 3° × round(L / 3°)`；徐州 `117.2°E → L0=117°`。
- 经差：`l = (L − L0)/ρ`（弧度）。
- 高斯投影正算（实用公式，保留至 `l^6`；`t=tanB`，`η²=e'²cos²B`，`N=a/√(1−e²sin²B)`，`X` 为子午线弧长）：

```text
x = X + N/2·sinB·cosB·l²
      + N/24·sinB·cos³B·(5 − t² + 9η² + 4η⁴)·l⁴
      + N/720·sinB·cos⁵B·(61 − 58t² + t⁴)·l⁶
y = N·cosB·l + N/6·cos³B·(1 − t² + η²)·l³
      + N/120·cos⁵B·(5 − 18t² + t⁴ + 14η² − 58η²t²)·l⁵
      + 500000
```

- 论文指出 `|l|<3.5°` 时正算精度约 0.001 m。
- 本项目实现采用 Krüger n⁶ 级数（与 PROJ 9.x 的 EPSG:4490→EPSG:4547 结果在 1e-6 m 内一致），并实现反算，用于把算例坐标转回经纬度显示。
- 坐标轴约定：**x 为北、y 为东**；`y` 含 500 km 假东偏移。算例 1 坐标即此约定。

### 3.2 球面距离、方位角与角度（第 4.2.2 节）

论文 JS 把地球视为半径 R 的球：

```text
cos c = cos(90°−latB)·cos(90°−latA)
      + sin(90°−latB)·sin(90°−latA)·cos(lngB−lngA)
D = R · c(rad)
sin(αAB) = sin(90°−latB)·sin(lngB−lngA)/sin c
```

方位角按 B 相对 A 的象限修正：

| 条件 | Azimuth |
|---|---|
| B 在 A 东北（第一象限） | A |
| B 在 A 西北（第二象限） | 360 + A |
| B 在 A 西南/东南（第三、四象限） | 180 − A |
| 同纬、B 在东 | 90° |
| 同纬、B 在西 | 270° |
| 同经、B 在北 | 0° |
| 同经、B 在南 | 180° |

论文用 `map.getDistance(point1, point2).toFixed(4)` 得到距离；本项目用椭球面 Vincenty 反算，并同时给出高斯平面反算距离/方位角。论文表 4-1 的三个点显示：网页距离 1694.8051 m / 1982.5891 m / 1333.8521 m，与 CGO 高斯平面距离相差约 0.3–4 m。

角度：设边 1 为起边、边 2 为终边，按两条边端点关系取

```text
同起点:       Angle = Az(2) − Az(1)
同终点:       Angle = Az(2) − Az(1)
1 起 = 2 终:  Angle = Az(2) − Az(1) − 180°
1 终 = 2 起:  Angle = Az(2) − Az(1) + 180°
```

规范化到 `[0,360°)`。本项目直接用三点 `(后视, 测站, 前视)` 计算：

```text
angle = (azimuth(station→foresight) − azimuth(station→backsight)) mod 360°
```

这比论文按线对象组合更直接，也避免线方向歧义。

### 3.3 平面网间接平差（式 3-18～3-35）

观测方程统一写为：

```text
V = B X − L,     Qxx = (Bᵀ P B)⁻¹
```

- **方向观测网**：每个测站一个定向角未知数；方向误差方程 `v = −Z_j + δα_jk − l`。
- **测角网**：参数为待定点坐标 `(x,y)`；每个角涉及后视 j、测站 k、前视 h 三点。
  - 近似角 `L0 = α_jk^0 − α_jh^0`
  - 常数项 `l = L − L0`
  - 误差方程 `v = δα_jk − δα_jh − l`
  - 系数（式 3-22）：`a,b` 为测站对后视/前视的偏导，`c,d` 为后视点，`e,f` 为前视点；统一乘 `ρ″=206265`。
  - 测角网 `P=I`。
- **测边网**：`v = −(ΔX/S)x_j − (ΔY/S)y_j + (ΔX/S)x_k + (ΔY/S)y_k − l`，`l=L−S0`。
  - 若一端已知，对应坐标改正项为 0；两端已知的边不列误差方程。
  - 定权 `P_S = σ0²/σ_S²`，`σ_S = a + b·S`（a 单位 mm，b 单位 ppm，S 单位 km；式 3-36/3-37）。
- 点位中误差（式 3-25/3-35）：`M = Mw·√(Qxx+Qyy)`。

### 3.4 表 3-1 控制网等级参数

| 等级 | 平均边长 km | 测角中误差 ″ | a mm | b ppm | 最弱边相对中误差 |
|---|---:|---:|---:|---:|---:|
| 二等 | 9 | 1.0 | ≤10 | ≤2 | 1/120000 |
| 三等 | 5 | 1.8 | ≤10 | ≤5 | 1/80000 |
| 四等 | 2 | 2.5 | ≤10 | ≤10 | 1/45000 |
| 一级 | 1 | 5.0 | ≤10 | ≤10 | 1/20000 |
| 二级 | <1 | 10.0 | ≤15 | ≤20 | 1/10000 |

按平均边长建议等级：`≥9 km 二等`、`[5,9) 三等`、`[2,5) 四等`、`[1,2) 一级`、`<1 km 二级`。

### 3.5 误差椭圆（式 3-38/3-39）

```text
Q = [[Qxx,Qxy],[Qxy,Qyy]]
K = √((Qxx−Qyy)² + 4Qxy²)
QEE = (Qxx+Qyy+K)/2
QFF = (Qxx+Qyy−K)/2
E = Mw√QEE,  F = Mw√QFF
φE = atan((QEE−Qxx)/Qxy)       （实现用 atan2(2Qxy, Qxx−Qyy)/2，保证象限）
```

地图绘制：以点为中心，长轴 E 沿 `φE`（从北顺时针），短轴 F 垂直；可调放大倍数。

### 3.6 边长相对中误差分母（图 5-7/5-12）

论文表中分母与边长的数值关系可反推为

```text
分母 = S / 0.01 m = 100·S
```

即等价于对每条边取固定 1 cm 的边长中误差；它与端点坐标的严格 Q 传播无关，所以两已知点之间的边 17 也得到有限分母。本项目同时输出论文口径分母与严格 Q 传播的边长中误差，并在页面注明差异。

### 3.7 单位口径（重要）

- 论文式 3-22 的 B 系数乘 `ρ″=206265`；若坐标改正数取 mm，则 `Q` 为 `mm²/(″)²`，`M=Mw·√(Qxx+Qyy)` 为 mm。
- 论文截图公布算例 1 `Qxx=0.6502, Qyy=0.3039, M=0.97 cm`。严格 mm² 计算约 `Qxx=65.019, Qyy=30.389, M=97.677 mm`；截图数值恰为严格值的 1/100（cm² 口径），且 `Mw·√(0.6502+0.3039)=9.768` 被论文同时标为 9.77 mm 与 0.97 cm。
- 本项目**两种口径都保留**：`q_mm2`/`mp_mm` 为严格 mm² 口径，`paper_q`/`paper_mp_mm` 为论文截图数值口径。网页结果表默认显示 `paper_q` 与 `paper_mp_mm`，并明确标注“论文数值口径”；测试同时锁定两套数值。**不得为迎合论文而修改第 13 节黄金期望值或严格公式。**

## 5. 离线底图规格（本项目新增）

1. 数据源：Copernicus GLO-30 DEM，瓦片 `Copernicus_DSM_COG_10_N34_00_E117_00_DEM`（AWS 公开 S3，一次性下载）。
2. 原始瓦片（约 47 MB）放 `data/cache/`，该目录已在 `.gitignore`；不得提交。
3. 裁剪范围：`117.10–117.30°E, 34.15–34.25°N`。
4. 渲染：浅色分层设色 + 晕渲 + 等高线（10 m 间隔，50 m 计曲线略深），整体接近论文浅色地图；可叠加经纬网/图廓，但不得使用任何在线底图或 OSM 数据。
5. 输出：`data/sample/thesis_basemap.png`（≤3 MB）与 `thesis_basemap.json`（bounds、尺寸、高程范围、等高距、数据源、离线标记）。
6. 网页以 Leaflet `imageOverlay` 加载本地 PNG；地图控件、标记、线、角弧、椭圆全部本地绘制；禁止任何 `http(s)://` 外部资源。
7. 服务只监听 `127.0.0.1`；测试中检查 HTML/JS 不含在线瓦片/地图 API 域名。

### 6.2 缺失（D2 要补齐）

1. **交互式建网**：地图点击选点→点库；构线→线库；构角→角库；删除行级联；当前网页基本只读。

3. **网库与等级**：表 3-1 下拉、平均边长建议等级、观测边/角勾选、精度计算按钮、最弱点/Q/M/限差、分母表、误差椭圆开关与放大。
4. **论文约定计算入口**：Web API 复用 D1 `thesis.build_network`；线性 `σS=a+bS`；`P=I`（测角）与边权；Q 的两种口径；3° 带 117°E；坐标文本/角度拓扑导出。
5. **离线底图**：徐州区域 Copernicus DEM 浅色底图（见 §5）；不得使用 OSM/在线瓦片。
6. **工程持久化**：保存/读取论文工程（SQLite），一键载入算例 1/2。

### 6.3 关键风险与决策

- **坐标口径**：算例 1 直接使用论文高斯坐标，避免把截图经纬度反算带来的米级差异；用户点击点才走“经纬度→高斯”。
- **Q 口径**：页面默认论文数值口径并明确标注；严格 mm² 值同时保留，避免“为了像论文而改公式”。
- **算例 2 点位**：未公布，只能近似；页面明确标注“近似复现”，不把近似结果冒充论文原值。
- **角度拓扑顺序**：论文正文说“顶点在中间”，但其 JS 代码与可复现 Q 都表明三元组首位是测站；D1 采用 `station_first`，页面导出也保持该顺序并在说明中注明。
- **离线**：不引入任何在线 SDK；Leaflet 本地文件；底图是 DEM 渲染的静态 PNG；服务绑定 127.0.0.1。
