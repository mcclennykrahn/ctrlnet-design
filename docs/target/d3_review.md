# D3 截图对照自查记录

本文件记录 `scripts/capture_target_match.py` 自动复刻论文图 4-1～5-13 后，
对照 `docs/target/figs/` 原图所做的界面检查与修正。原图、复刻图与左右对比图
均在 `outputs/target_match/`。

## 1. 对照方法

- 视口固定 `1280×630`（论文截图约 2.03 宽高比）；`device_scale_factor=1`。
- Playwright 只打开 `http://127.0.0.1:<port>/thesis`；脚本拦截所有请求，
  出现非本地请求即失败。
- 点位按论文经纬度换算为 Leaflet 像素，在 z20 下选择能落到 6 位小数的
  整数像素后真实点击地图；不使用“直接写 API”的捷径。
- 线、角、观测勾选、删除、计算均通过页面输入框、按钮、复选框完成。
- 用 PIL 生成左论文/右本地对比图，再拼成 `overview.png`。

## 3. 仍然存在的差异（有意保留）

1. **底图**：本地 DEM 分层设色/晕渲不是百度街道图；没有在线瓦片、OSM 或地图 API。
2. **表格列**：目标规格要求点库有“类型”、角库有“测站”，比论文原截图多一列；
   不使用论文的“起边/终边”两线定义法。
3. **额外工程控件**：工程名、保存/读取、算例 1/2、论文步骤下拉属于本项目增强，
   论文原页面没有。
4. **线库数值口径**：网页线长/方位由本地高斯平面坐标反算，论文用百度球面
   `getDistance`；同一条边通常相差 0–1 m、方位 0–0.2°，误差方程仍用平面坐标。
5. **图 5-4 的 19 个角**：论文只转录 14 组拓扑；截图额外画 5 个“图形角”（灰色），
   计算只使用 14 个已公布观测角，保证算例 1 的 `0.6502/0.3039` 不被改动。
6. **图 5-8/5-13 的新增观测**：论文未公布新增集合；截图脚本使用候选角局部搜索
   得到的集合，使显示值接近公布值（5-8 为 0.4634/0.1861，5-13 为
   0.1411/0.1298）。这些集合只用于截图，不写入 D1 黄金断言。

## 4. 离线与安全核对

- 页面 HTML/JS 不含 `http://` / `https://`；Leaflet 为包内静态文件。
- 底图只来自 `/api/thesis/basemap.png`（本机 DEM 渲染）。
- 截图脚本使用临时 SQLite；uvicorn 只绑定 `127.0.0.1`，结束后 terminate。
- Playwright 请求监听器确认 17 张截图过程中没有外部 URL。
