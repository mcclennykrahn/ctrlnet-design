# 《基于双模式离线地图的平面控制网精度估算与优化设计详细方案》总结

> 原文性质：一份面向工程平面控制网设计阶段的系统需求与计算规范，而非已实现软件。其主线是“离线地图选点 → 建立计划观测 → 先验协方差估算 → 网形/方案比较 → 成果导出”，重点在**设计阶段的精度预估**，不是实测数据的后验平差。

## 1. 目标与适用范围

**目标**：在真实离线地图与测区地形图上完成控制网布设与优化，使设计人员在不进场观测之前，就能比较不同点位、网形、观测类型和仪器精度下的预期成果，并输出可追溯、可回读的设计成果。

**适用范围**：

- 局部或工程尺度的**平面控制网**，包括测角网、测边网、边角网；测站方向值可作为扩展。
- 已知点可采用“精确固定”或“带精度约束”两种基准处理方式。
- 观测精度以先验标准差或协方差描述，支持独立观测与相关观测块。
- 成果以工程平面坐标（E、N）表达，角度内部用弧度、界面可用度分秒/角秒；高程用于地形、归算与高程辅助，平面精度主模型不直接解高程未知数。
- 交付对象兼顾设计人员与开发人员：既规定业务流程和交互，也规定数据结构、矩阵约定、接口与验证要求。

**明确不在范围内或未展开的内容**：GNSS 基线向量网、水准/高程网、三维联合平差、实测粗差探测与稳健估计、方差分量估计、投影变形与尺度因子的完整处理、大规模稀疏计算、多用户协同。这些是后续重设计需要补齐的主要缺口。

## 2. 业务流程

原文给出六步主流程（方案比较在第 12 节展开），可归纳为七步闭环，并以“输入版本 + 输入摘要”保证结果可追溯：

1. **创建工程**：录入名称、坐标参考、长度/角度单位、目标精度；校验单位与投影参数。
2. **组织底图**：选择全国矢量 MBTiles 地图包，导入 GeoTIFF/GeoPackage/扫描地形图；必要时进行配准。
3. **选点构网**：布设已知点、待定点，建立距离、角度（及方向）观测，分配稳定标识。
4. **设置计算**：选择精度模型、观测次数、基准约束；检查几何与约束，生成待定参数表与观测行表。
5. **分析调整**：运行估算，查看点位中误差、误差椭圆、最弱边/最弱点；复制方案并编辑。
6. **方案比较**：在可比条件下比较精度、工作量、达标情况，形成候选排序。
7. **选用导出**：冻结输入快照，输出可回读工程包、表格、图件和设计报告。

**状态机**：`editing → ready → calculating → valid / stale / failed`。仅显示设置变化不使结果失效；点位、启用观测、精度模型或基准变化则进入 `stale`。计算前复制不可变快照并计算 `input_hash`；只有当前方案仍与快照一致时，结果才被标记为最新。计算期间修改点位，旧结果进入原版本历史。

## 3. 模块划分

原文采用**四层结构**：

| 层次 | 组成 | 职责 |
|---|---|---|
| 交互显示层 | 地图画布、工程面板、数据表、结果面板 | 选点、构线、构角、图层控制、结果联动 |
| 工程管理层 | 点、观测、图层、方案版本 | 编辑事务、字段校验、状态与版本管理 |
| 计算层 | 精度引擎、方案评价 | 接收数值快照，返回协方差、指标、诊断 |
| 本地存储层 | 工程数据库、地图资源索引、结果文件 | SQLite、资源目录、工程包、缓存 |

**六个功能模块**：

| 模块 | 主要输入 | 主要输出 |
|---|---|---|
| 地图资源模块 | 文件路径、范围、缩放级别 | 图层描述、瓦片、覆盖/缺失状态 |
| 坐标与配准模块 | 源/目标坐标参考、配准点 | 转换坐标、仿射参数、残差、适用范围 |
| 工程编辑模块 | 点位与观测编辑命令 | 新输入版本、关联实体、受影响结果 |
| 精度引擎 | 点表、观测表、约束、精度模型 | 协方差、点边指标、椭圆、秩诊断 |
| 方案评价模块 | 多个可比结果、成本参数 | 指标变化、达标情况、候选排序 |
| 成果模块 | 选定方案、显示配置、模板 | 工程包、表格、图件、报告 |

设计上的关键点是：**计算层只接收确定的数值快照**，不直接读可变的工程表；编辑、计算、发布三段通过版本号与摘要解耦。

## 4. 数据模型

核心实体及关键约束如下：

| 实体 | 关键字段 | 约束/用途 |
|---|---|---|
| Project | id、name、crs_wkt、linear_unit、angle_unit、schema_version | 工程标识稳定；参考系统与单位必填 |
| Point | id、project_id、label、E、N、height、role、coordinate_source | UUID；点名工程内唯一；role 为 fixed/constrained/unknown |
| Observation | id、type、from_id、to_id、rear_id、station_id、front_id、enabled | distance 用两端点；angle 用后视—测站—前视三点；外键同工程 |
| PrecisionModel | id、kind、sigma_angle、distance_a、distance_b、repeats、correlation_group | 标准差为正；次数为正整数；单位与组合方式明确 |
| MapLayer | id、resource_id、crs、extent、opacity、registration_id、display_order | 资源引用；透明度 0～1 |
| Scenario | id、parent_id、name、input_version、input_hash、constraints、target_profile | 保存设计快照与比较条件 |
| Calculation | id、scenario_id、input_hash、status、engine_version、result_path | 结果绑定唯一输入版本；保存参数顺序与诊断 |

**存储与回读**：SQLite 保存结构化实体，资源目录保存图件、配准参数和结果附件；方案快照保存点表、启用观测、精度模型和基准约束，避免基础表后续修改污染历史方案。工程包由 manifest、数据库和必要资源组成，manifest 记录格式版本、依赖清单和摘要；回读先校验版本，再检查外键、文件引用、坐标参考和输入摘要。

**编辑事务**：删除点时列出关联距离、角度和约束，确认后一次提交，失败回滚；改名只改 label，观测按 id 保持关联；撤销恢复实体和计算有效性标记。

## 5. 数学核心

### 5.1 随机模型

- 测距标准差：`σ_s = sqrt(a² + (b×10⁻⁶×s)²)`，其中 `a` 为固定项（米），`b` 为比例项（ppm），`s` 为边长（米）。
- 测角标准差：`σ_β = σ″ × π/(180×3600)`；`n` 次独立同精度观测的均值可取 `σ/√n`，但必须明确参数描述的是单次观测还是均值，避免重复折减。
- 独立观测形成对角协方差 `Cl`（角度项为弧度²，距离项为米²）；相关观测形成对称正定的协方差块。
- 两种等价模式：绝对协方差模式直接使用 `Cl`；相对权模式写为 `Cl = σ₀²P⁻¹`，输出 `Cx = σ₀²(AᵀPA)⁻¹`，防止把 `σ₀²` 重复乘入。设计阶段 `σ₀²` 按先验模型取 1；后验 `σ₀²` 需要实测残差支持。

### 5.2 设计矩阵

- 待定参数按稳定顺序排列：`[E1, N1, E2, N2, …]`；固定点从参数向量中移除，但参与近似几何计算。
- 距离 `s_ij` 对点 j 的偏导：`∂s/∂E_j = ΔE/s`，`∂s/∂N_j = ΔN/s`；点 i 取相反数。
- 北起顺时针方向角 `α_ij`：`∂α/∂E_j = ΔN/s²`，`∂α/∂N_j = −ΔE/s²`；点 i 取相反数。
- 水平角 `β_ijk = α_jk − α_ji`，其行由两个方向行相减；同一测站两方向的贡献合并，三角点之外列置零。
- 若输入测站方向值，方向函数为 `α_jk − ω_j`，定向参数 `ω_j` 系数为 `−1`；由方向值派生角度时，要避免把原方向与派生角同时作为独立观测重复加入。

### 5.3 基准

- **固定点**：坐标未知数移除，视为精确，协方差取零。
- **带精度约束点**：保留坐标未知数，以坐标伪观测或等价约束加入，并使用其协方差。
- **基准秩检核**：检查平移（2）、旋转（1）、尺度（1）是否受到充分约束；纯测角网还需尺度信息；固定点数量不足或观测不连通时，矩阵秩亏。
- **自由网**：通过明确的内约束或广义逆扩展，并报告所采用的基准定义。

### 5.4 白化与 SVD

1. 对 `Cl` 作 Cholesky 分解：`Cl = L Lᵀ`。
2. 白化设计矩阵：`A_w = L⁻¹A`；独立观测时等价于每行除以该观测标准差。
3. 对 `A_w` 作 SVD：`A_w = U S Vᵀ`。
4. 满列秩时：`Cx = V diag(1/s_i²) Vᵀ`。
5. 秩阈值默认取 `max(m,u)×机器精度×最大奇异值`，另设可配置的病态提示阈值；记录阈值、参数尺度和奇异值范围，不能仅凭“矩阵可求逆”判断结果可靠。
6. 输出秩、观测数 `m`、未知参数数 `u`、冗余数 `m − rank(A)`；显著负特征值作为错误，舍入容差内的微小负值可截断。

### 5.5 精度指标

- 点位中误差：`m_p = sqrt(Cp11 + Cp22)`，同时给出 `σ_E`、`σ_N`；结果表以毫米显示，内部保留米制双精度。
- 误差椭圆：对 `Cp` 求特征值 `λ_max、λ_min`，标准半轴 `a = sqrt(λ_max)`、`b = sqrt(λ_min)`，主轴方位 `atan2(v_E, v_N)` 归化到 `[0,180°)`；置信度 `p` 的椭圆半轴乘 `sqrt(χ²₂,p)`，95% 时约 2.448；标准椭圆包络概率约 39.35%。
- 相对边长精度：`σ_s² = g_s Cx g_sᵀ`，其中 `g_s` 只在两端点相关参数列非零；相对精度用 `σ_s/s` 或 `1:(s/σ_s)`。
- 两点相对位置：`C_Δ = C_ii + C_jj − C_ij − C_ji`，再求相对误差椭圆。
- 绝对指标与相对指标分别排序、分别展示，避免混用。

### 5.6 第 13 节算例（原文回归基准）

A(0,0)、B(100,0) 固定；C(0,100)、D(100,100) 待定；参数顺序 `[E_C, N_C, E_D, N_D]`。基准方案 5 条距离（AC、BC、AD、BD、CD）+ 2 个 90° 角（C-A-B、A-B-D），共 7 个观测、4 个未知参数、3 个冗余。距离模型 `a=0.002 m、b=2 ppm`，角度先验标准差 1″。候选方案增加角 D-C-A，共 8 个观测、4 个冗余。

| 方案 | 点 | σ_E/mm | σ_N/mm | m_p/mm | 标准半轴 a/b/mm |
|---|---|---|---|---|---|
| 基准 | C | 0.468 | 1.651 | 1.716 | 1.652 / 0.466 |
| 基准 | D | 0.468 | 1.651 | 1.716 | 1.652 / 0.466 |
| 增补角 | C | 0.464 | 1.225 | 1.310 | 1.231 / 0.448 |
| 增补角 | D | 0.467 | 1.199 | 1.287 | 1.200 / 0.465 |

| 边 | 基准 σ_s/mm | 基准相对精度 | 增补 σ_s/mm | 增补相对精度 |
|---|---|---|---|---|
| AC | 1.651 | 1:60565 | 1.225 | 1:81608 |
| BC | 1.183 | 1:119522 | 0.849 | 1:166638 |
| AD | 1.183 | 1:119522 | 0.886 | 1:159530 |
| BD | 1.651 | 1:60565 | 1.199 | 1:83407 |
| CD | 0.643 | 1:155427 | 0.638 | 1:156844 |

该算例说明：在对称基准网中 C、D 精度相同；增加一个角度观测后点位精度改善，但各边改善不均匀；它可作为单位、偏导、基准、协方差传播和椭圆计算的联合回归用例。

## 6. 成果输出

- **工程成果**：可回读工程包（manifest + SQLite + 资源）、控制点表、观测配置表、基准约束表、点位精度表、边长及相对精度表、误差椭圆参数表、方案差异表、设计报告。
- **矩阵附件**：A、Cl、Cx 及行列索引；较大矩阵作为独立文件引用。
- **图件**：图层来源、工程坐标参考、比例尺、椭圆置信水平、绘图放大倍数；地图与表格联动。
- **可追溯性**：每份结果绑定输入版本、`input_hash`、引擎版本、参数顺序和诊断信息；固定点、带精度约束点分别标识。

## 7. 优点

1. **业务闭环完整**：从地图选点、配准、构网、精度估算到方案比较和成果导出，覆盖控制网设计的主要环节。
2. **版本与状态设计扎实**：不可变快照、`input_hash`、`stale/valid` 状态和旧任务归档，避免“结果与输入不一致”这一常见工程问题。
3. **双地图定位清晰**：真实地图负责地物辨认，地形图负责坡地、道路、高差和设站环境；两者通过工程坐标统一。
4. **数学链路完整且自洽**：随机模型、设计矩阵、基准处理、白化/SVD、协方差传播、误差椭圆、相对精度形成闭环；第 13 节算例可复算。
5. **工程化细节到位**：单位、角度包裹、近似坐标、秩阈值、病态提示、错误码、事务回滚、工程包回读等均有规定。
6. **离线优先**：地图、字体、图标、依赖本地分发，适合无网络或涉密工程环境。
7. **可验证性**：明确提出数值差分对照、独立线性代数复算、基准诊断、协方差传播和优化性质检查。

## 8. 不足、缺口与风险

| 类别 | 主要缺口 | 影响/风险 |
|---|---|---|
| 网型覆盖 | 仅平面测角/测边/边角网；无 GNSS 基线向量网、水准/高程网、三维联合平差 | 无法覆盖现代控制网“GNSS + 全站仪 + 水准”的常见组合；高程与平面分离 |
| 可靠性 | 只输出冗余数 `m−rank(A)`，没有多余观测分量 `r_i`、内部/外部可靠性、最小可探测粗差 | 无法识别“精度好但可靠性差”的网形；无法指导粗差探测能力设计 |
| 优化能力 | 仅支持手工复制方案、逐个试算候选边/角；无形式化优化模型 | 候选多时效率低，难以保证预算约束下最优或近似最优 |
| 地形利用 | DEM 主要用于显示、查询和等高线；无通视分析、地球曲率/折光改正 | 计划观测可能在实际不可通视；长边高程归算失真 |
| 坐标与投影 | 提到投影和尺度归算，但未系统处理投影尺度因子、高程归算、跨带、坐标变形 | 大范围或高海拔测区可能产生系统性尺度误差；平面模型适用范围不清 |
| 随机模型 | 支持对角/分块协方差，但无完整 VCV、方差分量估计、稳健估计 | GNSS 基线相关性、多类观测权比不合理时，精度评估失真 |
| 粗差处理 | 设计阶段无粗差探测；后验仅提到 `σ₀²` 需残差支持 | 无法回答“这个网能发现多大粗差”；实测数据缺乏数据 snooping 流程 |
| 数据模型 | Observation 采用宽表+可空外键；无 GNSS/水准专用字段，无观测方程注册机制 | 扩展新观测类型需改表；基线向量 3×3 协方差、水准路线等难以表达 |
| 计算性能 | 默认稠密 SVD；无稀疏/大规模策略 | 数千点以上网络可能内存和耗时不可接受 |
| 接口 | 端点较少；无优化、通视、基线导入、任务事件等接口 | 前端与计算服务耦合，扩展需改协议 |
| 产品化 | 单机单用户为主；地图数据版权、安装包体积、并发与权限未展开 | 推广到多用户/企业环境需补架构 |
| 验证 | 第 13 节仅覆盖简单边角网精度；缺可靠性、GNSS、水准、通视、优化回归 | 新功能容易“算得出但算不对”，缺少可复现的质量门槛 |
| 精度语义 | 以先验精度为主；置信椭圆基于二维正态和已知协方差假设 | 用户可能把设计精度误当实测精度；基准误差、模型误差未计入 |

**总体判断**：原文是一份质量较高的**平面边角网设计器**规范，数学主干可靠、工程约束清楚；但距离“多源控制网设计 + 可靠性 + 优化 + 地形/投影约束”的生产级平台仍有明显差距。重设计应保留其业务流程、版本机制、第 13 节算例和数学约定，在架构、数据模型、可靠性、优化和多网型上系统扩展。
