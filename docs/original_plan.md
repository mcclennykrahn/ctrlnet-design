# 基于双模式离线地图的平面控制网精度估算与优化设计详细方案
系统需求 数据结构 计算方法与交互设计

本方案规定一套平面控制网设计系统的业务流程、地图处理、工程数据、计算约定和结果表达。使用者在真实离线地理地图或测区地形图上布设候选点，建立计划观测，设置仪器精度与基准，通过点位和边长协方差比较网形。开发人员可据此组织界面、数据校验、计算模块和接口。

## 1 业务范围与工作流程
### 1.1 设计任务与输入
工程开始时录入测区名称、水平坐标参考、长度单位、预期精度目标和已知点。已知点包含成果坐标及其采用方式，候选点包含设计近似坐标与来源。用户选择测角网、测边网或边角网，建立计划观测，并为各类观测指定先验精度。

真实地图负责辨认测区及地物，地形图负责观察坡地、道路、高差和设站环境。精度计算使用工程平面坐标。每次计算绑定一个确定的输入版本，地图中可点选结果追溯到对应点和观测。

### 1.2 用户操作顺序
| 步骤 | 用户输入或操作 | 系统响应及流转条件 |
|---|---|---|
| 创建工程 | 名称、坐标参考、目标精度 | 校验单位与投影参数，生成工程标识和初始方案。 |
| 组织底图 | 选择地图包，导入测区图 | 读取范围与参考系统，必要时进入配准流程。 |
| 选点构网 | 已知点、待定点、距离、角度 | 分配稳定标识，展示拓扑和预计观测数量。 |
| 设置计算 | 精度模型、观测次数、基准 | 检查几何与约束，生成待定参数表和观测行表。 |
| 分析调整 | 运行估算，编辑方案副本 | 显示椭圆、最弱要素和前后变化，保留差异。 |
| 选用导出 | 选择方案、图层、成果范围 | 输出可回读工程包及带单位、参数和版本的报告。 |

### 1.3 功能边界与优先级
核心功能包括两种地图切换、坐标管理、配准、点线角编辑、先验精度估算、误差椭圆、方案对比及本地成果保存。测站原始方向值可作为测角模型的扩展，输入方向值时增加定向参数。坡距归算、剖面通视分析和矢量等高线导出作为独立扩展配置，避免与平面角、平距输入混用。

## 2 系统结构与模块接口
### 2.1 四层结构
交互显示层由地图画布、工程面板、数据表及结果面板组成。工程管理层维护点、观测、图层和方案版本。计算层接收确定的数值快照并返回精度与诊断。本地存储层保存工程数据库、地图资源索引和结果文件。

| 模块 | 接收的数据 | 返回的数据 |
|---|---|---|
| 地图资源模块 | 文件路径、范围、缩放级别 | 图层描述、瓦片、覆盖与缺失状态。 |
| 坐标与配准模块 | 源坐标参考、目标参考、配准点 | 转换坐标、变换参数、残差与适用范围。 |
| 工程编辑模块 | 点位修改和观测编辑命令 | 新输入版本、关联实体、受影响结果。 |
| 精度引擎 | 点表、观测表、约束、精度模型 | 协方差、点边指标、椭圆参数和秩诊断。 |
| 方案评价模块 | 多个可比计算结果、成本参数 | 指标变化、达标情况、候选方案排序。 |
| 成果模块 | 选定方案、显示配置、模板 | 工程包、表格、图件和设计报告。 |

### 2.2 调用与状态约定
编辑操作先完成字段校验，再在同一个事务中保存点和关联观测。计算前复制输入快照，并计算input_hash。计算任务返回后，仅当当前方案仍与快照一致，才将结果设为最新。用户在计算期间修改点位时，旧任务的返回值保存到原版本历史。

工程状态分为editing、ready、calculating、valid、stale和failed。仅显示设置变化时保留计算有效状态。点位、启用观测、精度或基准变化时进入stale。failed状态保留错误码和实体标识，使用户可从错误列表定位到具体问题。

### 2.3 本地部署
地图与计算服务绑定本机地址。浏览器通过同源接口访问本地资源，显示库、字体、图标、样式和依赖包随程序分发。数据路径以项目根目录为基准保存为相对路径，外部测区文件导入工程资源目录后再建立引用。运行入口提供启动、资源检查和停止服务操作。

## 3 全国真实离线地图
### 3.1 数据组织与覆盖
真实地图采用与Shortbread图层结构匹配的矢量MBTiles。中国区域与补充区域各自登记名称、版本、范围、最小和最大瓦片级别、格式及来源。加载多个包时，通过源标识区分，重叠区按预设图层优先级绘制，并检查地名和道路重复问题。

全国浏览提供海陆与城市定位，放大后加载道路、水系、建筑及地名。显示端从元数据获得真实最大数据级别，超出后使用过缩放显示。地图缩放倍数和底层数据详细程度分别记录在图层说明中。

### 3.2 瓦片读取与样式
| 处理环节 | 详细规则 |
|---|---|
| 瓦片定位 | 浏览器请求XYZ坐标。MBTiles按TMS保存时，数据库行号为2^z-1-y，列号保持x。z、x、y检查范围后使用参数化SQL查询。 |
| 传输编码 | 读取PBF原始字节。若数据带gzip头，响应中设置相应压缩标记，防止重复压缩或二次解压。缺少瓦片返回明确的空响应。 |
| 图层顺序 | 海陆背景、土地利用、地形叠加、水体、道路与建筑、地名、控制网、误差椭圆与交互标记依次组织。工程点和结果保持可辨。 |
| 字体与图标 | 文字使用本地字体或本地字形资源。样式中的字体、图标和外部资源引用逐一解析到本机路径。 |

### 3.3 覆盖校验和容错
图层加载前读取坐标范围与抽样瓦片，检查格式、图层名称和压缩。视窗超出数据范围时显示背景与覆盖提示。某个瓦片请求失败时保留其他正常图层，提供重试，并记录数据包、级别和行列号。

缓存键由地图包版本、源标识和z/x/y组成。资源更新后切换版本，旧缓存按容量规则回收。底图来源和署名在地图角落与成果来源表中保留。

## 4 自定义地形图导入与配准
### 4.1 文件识别与导入
| 文件类型 | 读取内容 | 进入工程前的检查 |
|---|---|---|
| GeoTIFF或带世界文件影像 | 像元、仿射变换、坐标参考、NoData | 检查参考系统、像元尺寸、旋转项、覆盖位置及波段解释。 |
| GeoPackage | 图层、几何类型、属性、参考系统 | 选择测区需要的点线面图层，检查无效几何和单位。 |
| JPG或PNG扫描图 | 像素宽高、图幅信息 | 选择配准模型，录入同名点并建立独立检查点。 |
| 本地瓦片包 | 格式、范围、级别、坐标约定 | 验证行号规则，确认是否能与工程视图转换。 |

导入界面先预览，再选择坐标参考和用途。没有坐标参考时要求用户指定依据。对坐标量级明显异常、范围落在测区之外或轴序颠倒的情况提示复核后再启用。

### 4.2 仿射配准模型
像素坐标(u,v)转换为工程坐标(E,N)，采用E=a0+a1u+a2v，N=b0+b1u+b2v。像素原点、像素中心及v轴向下的约定写入参数。三组不共线同名点可确定六个参数，工程配置宜使用六组或更多，覆盖四周和内部。

对于k组配准点，构造k×3矩阵M，每行是[1,u,v]，分别求解E和N参数。冗余点采用最小二乘，配准点存在不同可靠度时可加权。使用QR或SVD检查点位退化与参数可解性。

### 4.3 配准质量和应用
逐点残差为转换坐标减去已知工程坐标。平面残差统计可用sqrt(Σ(ΔE²+ΔN²)/k)，其定义随结果保存。独立检查点参与同样的坐标比较，但不参与参数求解，分别报告RMS和最大误差。

配准允许误差由测区用途配置。用户可停用异常配准点并重算，操作记录保留。保存模型、点对、残差、检查点、适用范围和参考系统。配准图上的选点经像素变换进入工程坐标，切换底图时按同一工程坐标定位。

## 5 高程数据与地形显示生成
### 5.1 源数据与参考
地形源采用约30米量级的高程数据，登记分幅索引、水平参考、高程基准及NoData。Copernicus GLO-30为DSM，包含地表和地物表面影响。不同纬度的格网地面间距以及源分幅东西向间距在资源说明中记录。

合并文件用于顺序读取与区域采样，虚拟拼接通过相对路径引用源分幅。缺失分幅和NoData像元独立识别，派生图对无效区域使用透明掩膜。源数据覆盖检查以有效像元为准。

### 5.2 配色与晕渲
高程配色采用分段线性插值。建议断点为0、200、500、1000、2000、3000、4000、5000、6500和9000米，颜色由浅绿、黄褐渐变至灰白。负高程有独立断点，数据低于海平面时仍按有效高程处理。

晕渲以315°方位、45°高度为默认光源。地表梯度gE、gN由邻域高程和地面米制间距计算，法向量为(-gE,-gN,1)归一化后与光照方向点乘。地理经纬度格网根据纬度换算米制间距，Web Mercator采样也作比例校正。

### 5.3 全国概览与按需细节
全国概览可采用16角秒降采样格网，生成带地理参考、透明通道和金字塔的彩色GeoTIFF。0至7级预生成PNG瓦片，高级别根据视窗采样源高程。每块瓦片外扩两至数个像元，计算梯度后裁去外扩区，避免拼接线。

显示瓦片使用双线性等适用方法采样，查询接口读取源高程并返回采样方法。并发渲染数作为配置项，默认4个任务，生成任务默认8个线程。缓存写入临时文件后原子替换，避免并发请求得到半成品。

### 5.4 等高线与地形查询
等高距配置为8至9级500米、10至11级200米、12至13级100米、14至15级20米。每五条加粗，缺失高程处中断。等高距和显示级别同时出现在图例中。栅格叠加用于浏览，可编辑成果另按指定范围和等高距导出矢量。

高程查询返回数值、单位、基准、源版本与采样方法。点位落在源范围外或无效像元时返回null及缺失原因。工程高程字段区分地图查询高程和测量成果高程，并记录来源。

## 6 坐标参考与几何约定
### 6.1 坐标字段
| 字段或量 | 系统统一约定 |
|---|---|
| 地图交换坐标 | longitude、latitude，单位度，水平参考WGS84，存储顺序为经度、纬度。 |
| 工程平面坐标 | E为东坐标、N为北坐标，单位米。界面采用X/Y名称时明确其与E/N的映射。 |
| 高程 | 以米保存，同时注明高程基准、来源及是否参与计算。 |
| 角度 | 求导与计算以弧度进行，界面可用度分秒或角秒，导出时带单位。 |

工程创建时选择测区适用的投影，记录EPSG标识或完整WKT及中央经线等必要参数。转换后抽查至少一个已知位置和一个已知距离。坐标参考缺失或转换不可用时阻止与其他图层直接叠加使用。

### 6.2 距离与方位角
点i至j的坐标差为ΔE=Ej−Ei、ΔN=Nj−Ni，平距s=sqrt(ΔE²+ΔN²)。北起顺时针方位角α=atan2(ΔE,ΔN)，显示归化到[0,2π)。系统内部调用函数时统一参数次序。

测站j、后视i、前视k的水平角β=wrap(αjk−αji)。数据结构明确存储rear_id、station_id、front_id。角度编辑器按这个顺序高亮三点，并显示方向箭头和计算值。求导围绕当前近似值连续展开，跨0°时采用包裹差值处理。

### 6.3 尺度与归算
平面设计矩阵采用投影平距。用户输入坡距或地面平距时，先选择相应归算流程并提供必要高差、投影和高程参数，再生成可参与模型的距离。归算设置与结果随观测保留。大型或跨带测区需先检查单一平面模型的适用范围。

地图选点精度用于描述近似位置可靠性。设计精度估算中的观测方差来自计划仪器和观测方式。需要将先验点位不确定度作为约束时，单独建模并注明来源。

## 7 工程实体与存储结构
### 7.1 数据模型

|---|---|---|

| Observation | id、type、from_id、to_id、rear_id、station_id、front_id、enabled | distance仅填写两端，angle填写三点。外键指向同一工程。 |
| PrecisionModel | id、kind、sigma_angle、distance_a、distance_b、repeats、correlation_group | 单位与组合方式明确，标准差必须为正，次数为正整数。 |

| Calculation | id、scenario_id、input_hash、status、engine_version、result_path | 结果与唯一输入版本关联，保存参数顺序和诊断。 |

### 7.2 存储与回读
工程采用SQLite保存结构化实体，资源目录保存图件、配准参数与结果附件。方案快照保存点表、启用观测、精度模型和基准约束，避免后来修改基础表影响历史方案。计算结果中记录待定参数排列顺序，用于解释协方差矩阵。

工程包包含manifest、数据库和必要资源，manifest登记格式版本、依赖清单和摘要。全国地图可由外部资源目录引用，导出时列出依赖和路径修复方法。回读先校验版本，再检查外键、文件引用、坐标参考及输入摘要。

### 7.3 编辑事务
删除点时列出相关距离、角度和约束。用户确认删除集合后一次提交，失败则回滚。点号重命名仅修改label，观测按id保持关联。撤销操作恢复实体和计算有效性标记，撤销记录有序保存。

## 8 界面布局与点线角操作
### 8.1 界面区域
左侧工程区显示工程参考系统、底图模式、图层列表和方案树。中间地图区承载点线角及结果。右侧属性区随选中对象展示坐标、角色、观测精度及约束。底部表格区提供点表、距离表、角度表、错误表和结果表，支持按点号定位。

工具状态取pan、add_point、add_distance、add_angle和edit。退出工具或按Esc清除未提交的临时对象。工具状态以图标、文字和光标共同表示。编辑提交前显示预览，避免单次误点形成错误观测。

### 8.2 选点与构线
在add_point状态点击地图，先将显示坐标转换到工程坐标，生成临时点，填写点名和角色后提交。已有点吸附按屏幕像素距离判断，阈值可配置，默认8像素。吸附候选显示点号，重叠点由列表选择。

构线按起点、终点两次选择，只允许选择有效工程点。提交时检查同点、零长度、重复启用观测及精度配置。重复观测若用于多测回，应明确合并次数或保存独立记录的方式。

### 8.3 构角与拖动
构角按后视点、测站、前视点顺序选取，临时图形逐步显示已选点。三点必须互异，两条方向长度大于几何容差。提交后表格同时列出点序、角度值与精度。接近0°或180°的构型给出几何提示，并由矩阵检核决定是否可解。

待定点拖动过程中只更新临时几何，松开后提交新坐标，刷新关联边长和角度并使结果过期。固定点默认锁定，修改需进入明确的坐标编辑操作。属性表输入与地图拖动采用同一校验入口。

### 8.4 底图切换
切换后保留工程对象、选择状态和方案。视图以地理中心及比例尺迁移，配准图不覆盖当前区域时提供"定位到图层范围"。结果图层以工程坐标重绘，椭圆放大倍数保持同一设置。

## 9 随机模型与基准约束
### 9.1 测距与测角标准差
独立固定项与比例项按方差叠加时，测距标准差σs=sqrt(a²+(b×10⁻⁶×s)²)，a以米输入，b以ppm输入，s以米计算。界面显示单位和换算后数值。若项目采用其他仪器模型，保存明确的模型类型与参数。

角秒标准差换算为弧度，σβ=σ″×π/(180×3600)。n次独立且同精度观测的均值可取σ/√n，用户需明确该参数描述单次观测还是均值，避免重复折减。系统误差分量可按共同参数或相关协方差处理。

### 9.2 权阵与相关性
独立观测形成对角协方差Cl，角度项单位为弧度平方，距离项为平方米。相关观测形成协方差块，矩阵应对称正定。界面显示协方差来源和相关组，输入非正定时阻止计算并定位到相关组。

绝对协方差模式直接使用Cl。若采用单位权方差与相对权阵模式，则写明Cl=σ0²P⁻¹，输出Cx=σ0²(AᵀPA)⁻¹，防止重复乘入σ0²。设计阶段按先验模型估算，后验单位权方差需要实际观测残差支持。

### 9.3 基准设置
固定点坐标从待定参数向量中移除，固定点视为精确时其协方差取零。带精度约束点保留坐标未知数，以坐标伪观测或等价约束加入，并使用相应协方差。固定精确与带精度约束在界面上分别标识。

检查平移、旋转与尺度是否受到充分约束。纯测角网还需尺度信息，两个具有不同已知坐标的点可能提供所需基准，但仍须结合观测连接与几何判断秩。自由网通过明确的内约束或广义逆模型扩展，报告对应基准定义。

## 10 设计矩阵与数值求解
### 10.1 参数与观测排列
对每个待定点按稳定顺序建立[E1,N1,E2,N2,...]参数向量。按观测标识稳定排序形成行表，每行保存观测号、类型、关联点和标准差。若包含测站定向未知数，附加在坐标参数后，并登记名称及单位。

### 10.2 距离系数
对距离sij，点j的偏导为∂s/∂Ej=ΔE/s、∂s/∂Nj=ΔN/s，点i的偏导取相反数。每行只写入有关待定参数的列。固定坐标参与近似几何，但不占未知参数列。

### 10.3 方向与角度系数
对北起顺时针方向αij，点j的偏导为∂α/∂Ej=ΔN/s²、∂α/∂Nj=−ΔE/s²，点i取相反数。水平角βijk=αjk−αji，角度行由两个方向行相减。相同测站在两方向中的贡献相加归并，三个点对应列之外均为零。

若输入测站方向值，可写方向观测函数为αjk−ωj，定向参数ωj的系数为−1。由方向值构成多个角时，要处理共享方向引起的相关性，避免同时将原方向与派生角作为独立观测重复加入。

### 10.4 白化与秩检查
对Cl作Cholesky分解Cl=LLᵀ，求解Aw=L⁻¹A。独立观测时相当于每行除以该观测标准差。采用SVD得到Aw=USVᵀ，满列秩时Cx=V diag(1/singular_value²)Vᵀ。

可先作列尺度归一化检查秩，并将尺度正确还原到参数协方差。默认秩阈值可取max(m,u)×机器精度×最大奇异值，另提供可配置的病态提示阈值。记录阈值、参数尺度和奇异值范围，避免仅以可求逆判断结果可靠。

### 10.5 输出与错误
输出参数协方差、矩阵秩、观测数m、未知参数数u和冗余数m−rank(A)。求解失败时返回秩亏、非正定协方差、无效几何或数值病态等原因，并关联到点、观测或约束。微小负特征值仅在舍入容差内截断，显著负值作为错误处理。

## 11 精度指标与地图表达
### 11.1 点位中误差
提取点p的二维协方差Cp，坐标标准差为σE=sqrt(Cp11)、σN=sqrt(Cp22)，点位中误差mp=sqrt(Cp11+Cp22)。结果表统一显示毫米，同时保留内部米制数值。最弱点按mp最大排序，差异在舍入容差内时并列标记。

### 11.2 误差椭圆
对Cp求特征值λmax、λmin，标准椭圆半轴为a=sqrt(λmax)、b=sqrt(λmin)，主轴由λmax对应特征向量给出。方位角采用atan2(vE,vN)，按[0,180°)归化。近圆椭圆的主轴方向标记为不稳定。

先验协方差已知、二维正态假设下，置信度p的椭圆半轴乘sqrt(χ²₂,p)，95%时约2.448。标准椭圆包络概率约39.35%。结果图例同时列出置信水平与绘图放大倍数。固定点的椭圆可用固定标识表达，带精度约束点按其计算协方差绘制。

### 11.3 相对精度
边长梯度对两个端点的坐标传播完整协方差，σs²=gs Cx gsᵀ，其中gs只在相关参数列非零。相对边长中误差为σs/s，以比值或1:(s/σs)表示。相对最弱边按σs/s最大确定，绝对最弱边可另按σs最大列示。

若分析两点相对位置，使用CΔ=Cii+Cjj−Cij−Cji，再求相对误差椭圆。对固定点按采用的基准协方差补齐相应项。相对指标与绝对点位指标分别展示，避免混用排序。

### 11.4 图表联动
点表选中某点时地图定位并突出其椭圆，边表选中时高亮相关两点及观测。颜色表达达标状态，文字和图例同时说明阈值。绘图放大只改变屏幕尺寸，报告中的数值与真实单位独立保存。

## 12 优化策略与方案比较
### 12.1 方案生成
从基准方案复制候选，允许增加或删除观测、调整次数、改变仪器配置以及移动候选点。每个候选记录父方案、改动清单和适用观测条件。仅改变绘图或底图时不需创建新的计算方案。

辅助建议可对用户给定的候选边和候选角逐一试算。候选先通过点位、几何、基准和外业可行性筛选，再计算精度变化。缺少现场可行性信息时标记为待确认，保留用户最终选择。

### 12.2 指标与目标
| 比较量 | 计算方式与意义 |
|---|---|
| 最弱点精度 | 所有待定点mp的最大值，同时列关键点指标。 |
| 最弱相对边 | 规定分析边集合中σs/s的最大值，集合随比较保存。 |
| 均衡性 | 列点位中误差的最大值、最小值和分布，观察精度集中问题。 |
| 工作量 | 按设站数、方向数、距离数、次数与配置成本表估算。 |
| 改善幅度 | 对越小越优的量，改善率=(基准值−候选值)/基准值。基准为零时显示绝对变化。 |

精度和成本约束优先按项目要求设定。需要排序时，可在达标方案内比较工作量，或采用明确公开的加权目标。保存权重、成本表和排序版本，并显示各项变化。

### 12.3 可比条件
比较前核对工程参考、固定基准、关键点集合和精度定义。删点后点集变化时，分别报告共同点的变化与全网变化。仪器或精度参数变化属于方案差异，列表显示。采用相同条件增加独立正权观测时，协方差理论上应保持或改善，这可用于检查实现。

### 12.4 选用流程
先排除约束不足和未满足关键精度门槛的方案，再核查新增观测的通视、设站和道路条件，最后比较工作量与精度收益。选定后冻结输入快照，在报告中保留基准方案和选用理由。

## 13 可复核的边角网设计示例
### 13.1 点位与观测配置
采用局部米制平面坐标。A(0,0)和B(100,0)作为精确固定点，C(0,100)与D(100,100)作为待定点，括号内依次为E和N。待定参数顺序为[EC,NC,ED,ND]。

基准方案有五条距离AC、BC、AD、BD和CD，以及两个水平角(C,A,B)和(A,B,D)，三点依次为后视、测站、前视。这两个角的几何值均为90°。距离AC、BD、CD均为100米，BC、AD均为约141.421356米。

所有计划观测相互独立。距离采用固定项a=0.002米、比例项b=2 ppm的方差叠加模型，角度均值的先验标准差为1角秒。这里的精度参数直接描述模型中的单条观测，不再按次数折减。基准方案有7个观测、4个未知参数和3个冗余。

### 13.2 增补观测
候选方案增加角(D,C,A)，在C测站以D为后视、A为前视，几何值为90°，先验标准差仍为1角秒，其余条件相同。候选方案有8个观测、4个未知参数和4个冗余。下表列出按本方案公式复算的先验精度，用于核对单位、偏导、约束和协方差传播。

|---|---|---|---|---|---|
| 基准 | C | 0.468 | 1.651 | 1.716 | 1.652 / 0.466 |
| 基准 | D | 0.468 | 1.651 | 1.716 | 1.652 / 0.466 |
| 增补角 | C | 0.464 | 1.225 | 1.310 | 1.231 / 0.448 |
| 增补角 | D | 0.467 | 1.199 | 1.287 | 1.200 / 0.465 |

| 边 | 基准σs 毫米 | 基准相对精度 | 增补σs 毫米 | 增补相对精度 |
|---|---|---|---|---|
| AC | 1.651 | 1:60565 | 1.225 | 1:81608 |
| BC | 1.183 | 1:119522 | 0.849 | 1:166638 |

### 13.3 解释与复核要点
点位结果保留三位小数毫米，排序使用舍入前数值。对称的基准网中C、D精度相同，最弱点并列。两条相同长度的固定点到待定点边AC、BD具有相同相对精度。误差椭圆默认使用标准半轴，若切换95%置信水平，再按统一系数放大。

该示例采用精确固定点和独立观测假设。复算时使用相同假设，并可用数值差分独立核对角度偏导。增加观测后对比点位中误差与最弱相对边，同时记录增加一次设站角度观测的工作量。

## 14 接口约定与异常处理
### 14.1 请求与结果
| 接口或命令 | 关键输入 | 返回值及语义 |
|---|---|---|
| GET /layers | 工程标识 | 图层类型、范围、坐标参考、资源版本与可用状态。 |
| GET /tiles/{source}/{z}/{x}/{y} | 资源标识、XYZ整数 | PBF或PNG，缺少瓦片返回空值语义，坐标越界返回参数错误。 |
| GET /elevation | 经度、纬度、采样方法 | 高程或null、单位、基准、源版本和缺失原因。 |
| POST /projects/{id}/points | 坐标、点类、来源、期望输入版本 | 新点id及输入版本，版本冲突返回409。 |
| POST /scenarios/{id}/calculate | 输入版本或快照摘要 | 计算任务id，完成后提供结果id与对应input_hash。 |
| GET /calculations/{id} | 计算id | 状态、诊断、点边精度、椭圆和结果文件引用。 |
| POST /comparisons | 多个结果id、指标与成本配置 | 可比性检查、变化表、达标项和排序。 |

### 14.2 数据校验
所有数值检查有限性，NaN和无穷拒绝入库。点位坐标使用双精度，精度参数大于零。用于方向和距离的两点间距按工程尺度设置最小容差，避免除零。坐标、观测和约束分别返回字段级错误信息。

错误码至少包括CRS_MISSING、RESOURCE_MISSING、INVALID_GEOMETRY、INVALID_PRECISION、COVARIANCE_NOT_POSITIVE_DEFINITE、RANK_DEFICIENT和VERSION_CONFLICT。每个错误包含可读说明、关联实体id和建议修正入口。

### 14.3 并发与失败恢复
同一方案以输入版本控制写入，重复计算请求可按快照摘要复用有效结果。资源读取与计算任务具有独立并发上限，运行中可取消任务。失败任务删除未发布的临时结果，保留诊断日志。应用重启后将未完成任务标记为中断，允许从已保存输入重新运行。

## 15 成果内容与验证要求
### 15.1 成果清单
工程成果包括可回读工程包、控制点表、观测配置表、基准约束表、点位精度表、边长及相对精度表、误差椭圆参数表、方案差异表和设计报告。矩阵附件保存A、Cl、Cx及行列索引，较大矩阵可作为独立文件引用。

点表显示点号、E、N、角色及坐标来源。观测表显示点序、类型、近似几何值、先验标准差及启用状态。报告图件包含图层来源、工程坐标参考、比例尺、椭圆置信水平及绘图放大倍数。数值表保留单位与显示精度。

### 15.2 验证设计
| 验证对象 | 具体方法 | 判定要求 |
|---|---|---|
| 坐标与配准 | 已知坐标转换、仿射配准点及独立检查点 | 轴序单位正确，检查误差符合工程设定。 |
| 切换与保存 | 同一方案往返切图并保存回读 | 点id、工程坐标、观测拓扑、输入摘要及数值结果一致。 |
| 偏导与求解 | 数值差分与解析偏导对照，独立线性代数复算第13节 | 在双精度与选定差分步长允许范围内一致，显示结果满足舍入精度。 |
| 基准诊断 | 撤除必要约束，建立孤立点、退化角或不合法协方差 | 返回明确错误，禁止发布有效精度结果。 |
| 协方差传播 | 核对含交叉项的边长方差及椭圆特征值 | 点边对应关系和单位正确，置信系数切换一致。 |
| 优化性质 | 在相同条件下增加独立观测，比较协方差与工作量 | 数值容差内不出现理论相悖退化，差异记录完整。 |

### 15.3 完整使用闭环
选取具有地物与起伏的测区，建立统一参考工程，在真实地图上选择候选点，再导入并配准地形图。录入已知点和计划观测后运行精度估算，按最弱要素建立候选方案。核查可行性、比较指标、选用方案并导出工程，回读后复现相同输入与精度结果。

系统由这一闭环连接地图选点、观测设计和数值评价。各阶段的输入、错误处理和结果版本均可追溯，为调整网形提供一致的设计依据。
