# Dashboard DEM profile legend

The terrain and line-of-sight legend now sits below the plot so it stays clear of measured data. A solid terrain line and dashed sightline match the legend swatches. Brighter, larger axis labels and inward-aligned distance endpoints keep ticks readable inside the plot.

Chromium before-and-after captures cover the visible P1–P2 and blocked P1–P4 profiles at 1440, 820, 390 and 320 CSS pixels. The focused check verifies the obstruction marker, legend position, tick bounds and absence of horizontal overflow or browser errors.

Evidence and test summaries are in `/workspace/ctrlnet-v08/cn_frontend_visual_profile_legend`.
