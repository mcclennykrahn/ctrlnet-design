# C2 观测方案优化对比

生成时间：2026-11-04 13:41:44 UTC

- 准则：`max_mp`（最小化最大点位中误差）；目标值越小越好。
- 成本：每条候选观测成本 + 测站首次使用固定成本；测站在候选集合中首次使用时只收一次。
- 方法：
  - `greedy`：按单位成本边际收益贪心加入；
  - `local_search`：贪心后做 1 换 1 局部搜索；
  - `exact`：分支定界，候选 ≤ 20，预算约束下证明全局最优；
  - `milp`：逐点/逐边线性代理 MILP（SciPy HiGHS），求解后用真实平差目标做 1 加/1 换 1 校正，**属于近似**。

## 说明与限制

- 分支定界使用“加入全部剩余观测后的目标值”作为单调下界；增加独立观测不会使 `Cx` 变差，因此剪枝不丢失全局最优。
- 当候选方向观测引入新的定向未知数时，A/D/E 的 `Cx` 维数会变化，分支定界自动关闭该下界，退化为带预算剪枝的精确枚举，仍保证最优。
- MILP 只是线性代理：逐点 `mp`/最弱边贡献被一阶累加，与真实协方差目标不一致，故结果标记为非精确；最终值均用 `solve` + `analyze_precision` 复算。
- 时间包含 Python 平差与评价开销，受机器负载影响；精确法在小规模下通常仍为毫秒级。
