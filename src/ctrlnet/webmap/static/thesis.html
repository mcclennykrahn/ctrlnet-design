#1 角度测量原理

把地球近似为球面，用三面角余弦公式由两点经纬度求球面距离与方位角；再由球面正弦公式求方位角，并按目标点所在象限修正到 0–360°。测站处两方向方位角之差即为水平角。

cos c = cos(90°−BB)cos(90°−BA) + sin(90°−BB)sin(90°−BA)cos(LB−LA)

α = atan2(ΔE, ΔN)，角 = (α前视 − α后视) mod 360°

#2 坐标转换原理

将 CGCS2000/WGS84 大地坐标 (B,L) 投影到 3° 带高斯平面。徐州取中央子午线 117°E，东坐标加 500 km 假东；x 为北、y 为东，供间接平差使用。

L0 = 3° × round(L/3°)，l = (L−L0)/ρ

x = X + N sinB cosB l²/2 + …，y = N cosB l + … + 500000

#3 精度估算原理

按测角/测边误差方程组成 B 矩阵，间接平差 V=BX−L，协因数 Q=(BᵀPB)⁻¹。最弱点中误差 M=Mw√(Qxx+Qyy)，并与限差比较；误差椭圆由 E、F、φE 三个元素确定。

Q = (BᵀPB)⁻¹，M = Mw√(Qxx+Qyy)

E,F = Mw√((Qxx+Qyy±K)/2)，K=√((Qxx−Qyy)²+4Qxy²)
